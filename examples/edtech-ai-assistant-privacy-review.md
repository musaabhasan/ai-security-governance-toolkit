# EdTech AI Assistant Privacy Review Example

This example shows how to document privacy considerations for a student-facing AI assistant.

## Scenario

An education organization wants to pilot an AI assistant that answers course policy questions, summarizes approved learning resources, and routes unresolved questions to staff.

## Review Notes

| Area | Example Assessment |
| --- | --- |
| Users | Students and teaching staff |
| Data classes | Course content, support questions, limited account metadata |
| Excluded data | Grades, disciplinary records, health information, payment data |
| Provider processing | Hosted model with contractual data protection terms required |
| Logging | Prompt and output logs retained for safety review with redaction controls |
| Human oversight | Staff review for unresolved or high-impact student support requests |
| Approval gate | Privacy, security, and academic owner approval before pilot launch |

## Required Evidence

- Completed AI system intake
- Data flow record
- Vendor due diligence questionnaire
- Logging and retention checklist
- Pilot success and incident criteria
