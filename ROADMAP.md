# Roadmap

## Phase 1: Governance Foundation

- Add AI use-case intake workflow.
- Add control catalog.
- Add risk and evidence registers.
- Add EdTech AI assistant example.
- Add prompt injection and outage playbooks.

## Phase 2: Practical Assurance

- Add control test procedures.
- Add sample completed evidence pack.
- Add vendor AI due diligence questionnaire.
- Add RAG and embeddings review template.
- Add AI logging and retention checklist.

## Phase 3: Policy as Code

- Expand OPA examples for:
  - data classification decisions
  - human approval gates
  - tool allowlists
  - high-impact action denial
  - regulated-data restrictions
- Add tests for Rego policies.
- Add GitHub Actions policy validation.

## Phase 4: External Contribution Alignment

- Map selected controls to OWASP GenAI Security guidance.
- Map selected controls to NIST AI RMF functions.
- Add examples that can support future contributions to OWASP, OpenMetadata, OPA, and AI security tooling.

## Phase 5: Education and Public Sector Pack

- Add LMS AI assistant governance profile.
- Add assessment integrity AI risk checklist.
- Add student data privacy review.
- Add AI service continuity scenario library.
- Add workshop slides or facilitation guide.
