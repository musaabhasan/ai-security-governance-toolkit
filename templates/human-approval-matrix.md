# Human Approval Matrix

Use this matrix to decide when AI-assisted actions require explicit human approval.

## Approval Levels

| Level | Description | Example |
| --- | --- | --- |
| Inform | AI output may be used without approval, but activity is logged | Drafting low-risk internal text |
| Review | A person must review before use | Summaries used in operational decisions |
| Approve | A named approver must approve before execution | Sending external notices or changing records |
| Dual approve | Two roles must approve before execution | High-impact decisions or privileged tool use |
