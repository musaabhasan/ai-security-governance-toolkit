# Template Index

This index lists the reusable governance templates included in the toolkit.

| Template | Purpose |
| --- | --- |
| [Agentic Tool Review](agentic-tool-review.md) | Use this template before allowing an AI agent or assistant to invoke tools, APIs, scripts, data stores, workflow actions, or external services. |
| [AI Access Review](ai-access-review.md) | Use this template to review user, administrator, service account, and tool permissions for AI systems. |
| [AI Access Recertification Report](ai-access-recertification-report.md) | Use this report to review stale access, privileged roles, service accounts, API keys, break-glass access, and high-impact agent tool permissions. |
| [AI Change Impact Assessment](ai-change-impact-assessment.md) | Use this template when an AI system, model, provider, integration, data source, or workflow changes after approval. |
| [AI Control Evidence RACI](ai-control-evidence-raci.md) | Use this template to assign accountability for AI security controls and the evidence needed to prove that those controls are operating. It is intended for governance reviews, internal audit preparation, and operating-model design. |
| [AI Control Test Evidence Pack](ai-control-test-evidence-pack.md) | Use this pack to document test objective, population, sample, evidence inventory, result assessment, exceptions, and remediation for AI control operating-effectiveness reviews. |
| [AI Data Flow Record](ai-data-flow-record.md) | Use this record to document how data enters, moves through, and leaves an AI system. |
| [AI Decision Contestability Review](ai-decision-contestability-review.md) | Use this template before approving AI-supported decisions that need notice, explanation, correction, appeal, human review, and remediation controls. |
| [AI Emergency Stop Drill](ai-emergency-stop-drill.md) | Use this template to test whether an AI system, assistant, model gateway, RAG workflow, or agent can be paused, contained, rolled back, and restarted safely. |
| [AI Evaluation Dataset Contamination Review](ai-evaluation-contamination-review.md) | Use this template before relying on evaluation scores to check benchmark leakage, holdout exposure, synthetic reuse, answer-key retrieval, reviewer conflicts, and vendor boundary controls. |
| [AI Human Review Calibration](ai-human-review-calibration.md) | Use this template to test whether human review is independent, consistent, evidence-based, and resistant to automation bias. |
| [AI Data Lineage Report](ai-data-lineage-report.md) | Use this report to review data provenance, source ownership, transformation evidence, legal basis, retention, transfer, and review freshness before release or audit. |
| [AI Data Deletion Evidence Report](ai-data-deletion-evidence-report.md) | Use this report to review deletion evidence across prompts, outputs, files, embeddings, logs, vector stores, and third-party processors. |
| [AI DPIA Triage Report](ai-dpia-triage-report.md) | Use this report to identify privacy review triggers, owner queues, and launch blockers before AI systems process personal, student, or sensitive data. |
| [AI Evidence Quality Report](ai-evidence-quality-report.md) | Use this report to review stale, missing, expired, unowned, or incomplete AI governance evidence before approval, audit, or control testing. |
| [AI Evidence Retention Schedule](ai-evidence-retention-schedule.md) | Use this schedule to define retention, storage, deletion, legal-hold, privacy-minimization, and ownership expectations for AI governance evidence. |
| [AI Evaluation Evidence Report](ai-evaluation-evidence-report.md) | Use this report to review evaluation dataset lineage, model/prompt/index metadata, security coverage, human review, pass rates, failure severity, and evidence freshness before release decisions. |
| [AI Exception Aging Report](ai-exception-aging-report.md) | Use this report before governance forums, risk acceptance reviews, internal audit preparation, and control testing to identify expired, expiring, missing-expiration, and inconsistent AI exceptions. |
| [AI Governance Escalation Decision Tree](ai-governance-escalation-decision-tree.md) | Use this decision tree to route AI requests, incidents, provider changes, tool access, and research risks to privacy, security, academic, legal, procurement, or executive review. |
| [AI Governance Review Agenda](ai-governance-review-agenda.md) | Use this agenda to run repeatable AI governance forums with required participants, pre-read evidence, decisions, risk acceptance, and follow-up tracking. |
| [AI Incident Severity Matrix](ai-incident-severity-matrix.md) | Use this matrix to classify AI-related incidents consistently before escalation, communications, containment, and post-incident review. |
| [AI Incident Evidence Report](ai-incident-evidence-report.md) | Use this report to review AI incident evidence gaps across timelines, containment, preserved logs, privacy review, communications, root cause, and remediation queues. |
| [AI Logging And Retention Checklist](ai-logging-retention-checklist.md) | Use this checklist before enabling prompt, output, embedding, tool-call, or administrative logs for AI systems. |
| [AI Agent Memory Governance Register](ai-agent-memory-governance-register.md) | Use this register to document persistent memory assets, write rules, retrieval boundaries, lifecycle evidence, deletion proof, and approval decisions for AI agents and assistants. |
| [AI Agent Memory Governance Report](ai-agent-memory-governance-report.md) | Use this report to review consent, deletion, stale-fact handling, access boundaries, provider transfer, and owner queues before enabling persistent memory. |
| [AI Procurement Scoring Worksheet](ai-procurement-scoring-worksheet.md) | Use this worksheet to score AI vendors, hosted models, embedded AI features, and agent platforms before purchase, renewal, or expansion. |
| [AI Red-Team Test Plan](ai-red-team-test-plan.md) | Use this template to plan and record AI red-team testing before production release, major model changes, new tool access, or high-impact workflow changes. |
| [AI Retrieval Integrity Review](ai-retrieval-integrity-review.md) | Use this review before approving, changing, or auditing RAG systems, vector stores, knowledge bases, semantic search, or long-term memory retrieval. |
| [AI Risk Register Report](ai-risk-register-report.md) | Use this report before governance forums and audit planning to summarize residual risk by theme, owner queue, and review-date status. |
| [AI Risk Tiering Decision Record](ai-risk-tiering-decision-record.md) | Use this record to classify an AI system into a governance risk tier, set the minimum control baseline, route approvals, and define review cadence. |
| [AI Rollback Readiness Report](ai-rollback-readiness-report.md) | Use this report to review rollback runbooks, drills, baselines, traffic-shift plans, schema compatibility, credential rollback, communications, and approvals before AI releases. |
| [AI Shadow Use Discovery Triage](ai-shadow-ai-discovery-triage.md) | Use this template to triage unmanaged AI use discovered through telemetry, expenses, surveys, DLP alerts, support tickets, procurement, or self-disclosure. |
| [AI Synthetic Data Release Review](ai-synthetic-data-release-review.md) | Use this template before creating, sharing, publishing, or reusing synthetic data for AI development, evaluation, research, education, vendor testing, or public demonstration. |
| [AI System Decommissioning Checklist](ai-system-decommissioning-checklist.md) | Use this checklist when retiring, replacing, pausing, or materially reducing an AI system, model, assistant, agent, or AI-enabled vendor service. |
| [AI Third-Party Dependency Report](ai-third-party-dependency-report.md) | Use this report to review AI providers, subprocessors, assurance evidence, DPA status, exit plans, and continuity gaps before release, renewal, or audit. |
| [AI Tabletop Evidence Report](ai-tabletop-evidence-report.md) | Use this report to review tabletop exercise evidence, decision logs, containment, communications, fallback, privacy review, and remediation readiness. |
